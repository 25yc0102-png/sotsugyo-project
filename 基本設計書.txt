基本設計書

1. システム概要
本プロジェクトは、Python を用いた電卓アプリと、ブラウザ上で動作するテトリスゲームを含む学習用・開発用の小規模アプリケーション群である。リポジトリ内には、Tkinter ベースの電卓、Gradio ベースの電卓、Web フロントエンドのテトリスゲームが含まれており、各機能を独立して開発・検証できる構成として設計している。

2. 目的
- 数式入力に対し安全に計算を行う
- GUI 上で直感的に電卓を操作できるようにする
- Web 上でテトリスを動作させる
- Python と JavaScript の連携を学習しながら、分離したモジュールを組み合わせる
- 卒業制作の実装・検証・デバッグの実習を行える環境を整える

3. 対象ユーザー
- Python の基本構文と GUI 開発に興味がある学生
- JavaScript でゲーム開発を体験したい学生
- 共同開発環境の構築と GitHub 管理を学びたい学生

4. システム構成
4.1 Python 電卓
- 対象ファイル: calculator.py
- 実装方式: Tkinter
- 主な機能:
  - 数字入力
  - 四則演算
  - 括弧入力
  - クリア機能
  - バックスペース機能
  - 計算結果表示
  - エラー表示

4.2 Gradio 電卓
- 対象ファイル: gradio_calculator.py
- 実装方式: Python + Gradio
- 主な機能:
  - 数式のテキスト入力
  - 計算結果の表示
  - 入力エラー時のメッセージ表示

4.3 テトリスゲーム
- 対象ファイル: index.html, style.css, script.js
- 実装方式: HTML / CSS / JavaScript
- 主な機能:
  - ゲーム開始
  - ブロック落下
  - 左右移動
  - 回転
  - ハードドロップ
  - ライン消去
  - スコア計算
  - レベル変動
  - ゲームオーバー判定

5. 機能要件
5.1 電卓機能
- 数字と演算子を入力できる
- 四則演算を実行できる
- 括弧を含む式を処理できる
- 0 で割る場合はエラー表示とする
- 不正な式入力時は、適切なメッセージを返す
- 計算結果を画面に表示する

5.2 テトリス機能
- 10 列 × 20 行のゲーム盤を持つ
- ブロックの落下を制御する
- 回転時に衝突判定を行う
- ラインが揃うと消去し、スコアを加算する
- 速度はレベルに応じて変化する
- ゲームオーバー時に停止する

6. 非機能要件
- Python 版電卓はローカル環境で動作すること
- Gradio 版電卓はブラウザで簡単に操作できること
- テトリスはブラウザ上で軽快に描画されること
- エラー時にユーザーへわかりやすい表示を行うこと
- コードは読みやすく保守しやすい構造にすること

7. データ設計
7.1 電卓のデータ
- 入力文字列
- 計算式の AST 解析結果
- 演算結果
- エラーメッセージ

7.2 テトリスのデータ
- ゲーム盤（2次元配列）
- 現在のブロック
- 次のブロック
- スコア
- ライン数
- レベル
- ゲーム状態（進行中 / 終了）

8. プログラム構成
- calculator.py
  - 電卓アプリの本体
  - 式の安全な評価ロジックを実装
- gradio_calculator.py
  - Gradio で動作する計算インターフェース
- index.html
  - テトリスの画面レイアウト
- style.css
  - 見た目とレイアウトの定義
- script.js
  - ゲームロジック、描画、操作処理
- test_calculator.py
  - 電卓の単体テスト
- test_gradio_calculator.py
  - Gradio 電卓のテスト

9. 画面設計
9.1 電卓画面
- 画面上部に入力欄を配置する
- 数字と演算子をボタン化する
- クリア、削除、計算ボタンを配置する
- 結果は入力欄に表示する

9.2 テトリス画面
- 左側にゲーム盤を表示する
- 右側に next ブロックを表示する
- 上部にスコア、ライン、レベル表示を配置する
- スタートボタンを配置する

10. 処理フロー
10.1 電卓の処理フロー
1. ユーザーがボタンまたはキーボードで入力する
2. 表示欄へ追加する
3. 「=」を押すと計算を実行する
4. 式を AST として解析する
5. 計算結果を出力する
6. エラー時は Error またはメッセージを表示する

10.2 テトリスの処理フロー
1. ゲーム開始ボタンを押す
2. ブロックを生成する
3. 落下処理を繰り返す
4. 入力操作（左右移動・回転・落下）を反映する
5. 衝突判定を行う
6. ライン消去とスコア更新を行う
7. ゲームオーバー判定を行う
8. 画面を再描画する

11. テスト方針
- 単項演算と二項演算が正しく動作することを確認する
- 0 で割るときに例外として扱われることを確認する
- 計算式に不正な入力があった場合にエラーを返すことを確認する
- テトリスの描画と落下処理が正常に動作することを確認する
- スコアとレベル更新が想定通りに処理されることを確認する

14. まとめ
本プロジェクトは、単一機能のアプリではなく、Python と Web 技術を組み合わせて複数の小さなアプリケーションを実装・検証するための学習型プロジェクトである。特に電卓とテトリスは、条件分岐・データ構造・描画処理・ユーザー入力の扱いを学ぶ上で有効な題材であり、卒業制作の基礎技術の習得に適している。
