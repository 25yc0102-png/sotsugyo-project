# めしガチャ

質問への回答に合わせて近くのお店を3店抽選するローカル Web アプリです。金属色の3リールに店名・ジャンルを表示し、停止後は同じ3店の詳細を下に表示します。レバーを引くと別の候補を抽選します。

## GitHub Pages での公開

リポジトリの `main` ブランチに変更を push すると、GitHub Actions がこのフォルダーの静的ファイルを GitHub Pages に公開します。初回は GitHub リポジトリの **Settings > Pages** で公開元を **GitHub Actions** に設定してください。公開 URL は `https://25yc0102-png.github.io/sotsugyo-project/` です。

GitHub Pages で公開できるのは画面の静的ファイルです。店舗検索には API キーを安全に扱うサーバーが必要なため、Pages 上では検索できません。検索機能を使う場合は、以下の手順でローカルサーバーを起動してください。API キーを HTML や JavaScript に埋め込んで公開しないでください。

## 起動方法

1. PowerShell でこのフォルダーへ移動し、`Set-ExecutionPolicy -Scope Process Bypass -Force; ./server.ps1` を実行します。
2. 起動時に表示される API キー入力では、キーが画面に表示されない状態で入力して Enter を押します。
3. 起動時に表示される URL をブラウザーで開きます。ポート `5180` が使用中の場合は、空いているポートを自動で選びます。
4. ページを開くと位置情報を取得し、ジャンルと予算の選択で質問が自動的に進みます。「戻る」で選択を保ったまま前の質問へ戻れます。居酒屋では雰囲気と料理・店の種類を複数選択し、最後に「めしガチャを回す」を押します。結果のレバーを引くと、候補の中から別の3店を抽選します。位置情報が使えない場合は、住所・駅名から検索地点を設定できます。

API キーはサーバー起動時に入力し、ローカルサーバーのメモリーにのみ保持されます。サーバー停止時に消去され、Web ページ、GitHub、ブラウザーの保存領域には書き込みません。

## 利用上の注意

- ホットペッパーグルメ Webサービスの利用規約とガイドラインに従ってください。
- API のクレジットをフッターに表示し、API 由来の写真には画像提供元を表示しています。
- 現在地検索にはブラウザーの位置情報許可が必要です。
- 地名検索には Photon と OpenStreetMap のデータを使用し、ページ上にクレジットを表示しています。
- サーバーは `127.0.0.1` のみに bind するため、この PC 内での利用を想定しています。
