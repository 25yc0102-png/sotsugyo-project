# めしガチャ Vue UI

Vue 3 を CDN から読み込む画面確認用プロトタイプです。ジャンル・予算・好み・検索範囲を選び、モックデータから候補を抽選します。Node.js や npm は必要ありません。

## プレビュー

1. このフォルダーの `index.html` をエクスプローラーで開きます。
2. Vue の読み込みにインターネット接続が必要です。ページが表示されないときは、ネットワークやCDNへのアクセスが制限されていないか確認してください。

簡易HTTPサーバーから確認する場合は、PowerShell でこのフォルダーを開いて次を実行し、表示されたアドレスをブラウザーで開きます。

```powershell
py -m http.server 8000
```

終了するときは PowerShell で `Ctrl+C` を押します。

## データとセキュリティ

- 店舗データは `app.js` 内にある画面確認用の架空データです。
- 店舗検索APIや位置情報には接続せず、API キーや個人情報をブラウザーに保存しません。Vue 本体の読み込みには unpkg CDN へ接続します。
- Vue はバージョンを固定し、Subresource Integrity（SRI）で読み込むファイルを検証します。CDNが利用できないと画面は動作しません。
- 店舗名などは Vue の通常のテキスト描画で表示します。外部入力を HTML として挿入する `v-html` は使用しません。
- API 連携時は `searchShops` をバックエンド API 呼び出しに置き換えます。API キーは Vue 側に置かず、バックエンドで管理します。
- `server.ps1` は旧画面用で、このCDN版のプレビューには使いません。
