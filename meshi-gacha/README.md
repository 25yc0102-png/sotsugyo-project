# めしガチャ Vue UI

Vue 3 と Three.js を CDN から読み込む画面確認用プロトタイプです。場所、予算、腹具合、ジャンル、好み、検索範囲を順に選び、モックデータから候補を抽選します。結果画面ではThree.jsで作成した筐体をドラッグして角度を変えられます。Node.js や npm は必要ありません。

## プレビュー

1. PowerShell でこのフォルダーを開き、次のコマンドを実行します。

```powershell
py -m http.server 8000
```

2. ブラウザーで `http://localhost:8000` を開きます。Three.jsをESモジュールとして読み込むため、`index.html` を直接開くのではなくHTTPサーバーを使ってください。
3. Vue と Three.js の読み込みにインターネット接続が必要です。ページが表示されないときは、ネットワークやCDNへのアクセスが制限されていないか確認してください。

終了するときは PowerShell で `Ctrl+C` を押します。

## データとセキュリティ

- 店舗データは `app.js` 内にある画面確認用の架空データです。表示する距離や条件との一致も実店舗を示すものではありません。
- 駅名・地名は画面に表示するだけで、地名解決や店舗検索APIには接続しません。現在地を選んだ場合はブラウザーの許可を得て座標を取得し、開いている画面のメモリー内だけに保持します。API キーや位置情報をブラウザーの保存領域には書き込みません。
- Vue 本体とThree.jsの読み込みには unpkg CDN へ接続します。Three.jsは結果画面で読み込まれます。
- Vue はバージョンを固定し、Subresource Integrity（SRI）で読み込むファイルを検証します。CDNが利用できないと画面は動作しません。
- 店舗名などは Vue の通常のテキスト描画で表示します。外部入力を HTML として挿入する `v-html` は使用しません。
- FastAPI 連携時は `searchShops` をバックエンド API 呼び出しに置き換え、リクエストとレスポンスの形式を担当者間で合意してください。API キーは Vue 側に置かず、バックエンドで管理します。
- `server.ps1` は旧画面用で、このCDN版のプレビューには使いません。
