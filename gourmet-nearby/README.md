# まちめし

現在地の周辺にある飲食店を、ホットペッパーグルメ Webサービス API で検索するローカル Web アプリです。

## 起動方法

1. PowerShell でこのフォルダーへ移動し、`Set-ExecutionPolicy -Scope Process Bypass -Force; ./server.ps1` を実行します。
2. 起動時に表示される API キー入力では、キーが画面に表示されない状態で入力して Enter を押します。
3. `http://127.0.0.1:5180/` をブラウザーで開きます。
4. 検索範囲を選び、「近くのお店を見る」を押して位置情報の利用を許可します。位置情報が使えない場合は、住所・駅名・地名を入力して検索できます。

API キーはサーバー起動時に入力し、ローカルサーバーのメモリーにのみ保持されます。サーバー停止時に消去され、Web ページ、GitHub、ブラウザーの保存領域には書き込みません。

## 利用上の注意

- ホットペッパーグルメ Webサービスの利用規約とガイドラインに従ってください。
- API のクレジットをフッターに表示し、API 由来の写真には画像提供元を表示しています。
- 現在地検索にはブラウザーの位置情報許可が必要です。
- 地名検索には Photon と OpenStreetMap のデータを使用し、ページ上にクレジットを表示しています。
- サーバーは `127.0.0.1` のみに bind するため、この PC 内での利用を想定しています。
